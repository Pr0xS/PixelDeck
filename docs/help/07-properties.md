Context-sensitive: shows different controls depending on the selected layer's type, organized into Layout / Style / Content tabs. Common to most layers: position, rotation, opacity, blur, drop shadow.

Use **Copy style** / **Paste style** (also Ctrl/⌘ + Alt + C/V) to match formatting between two layers of the **same type** — colors, fonts, fills, strokes, shadows, and similar style fields, never position/size. Paste writes into whichever scope you're currently viewing (Base, or the active format/locale if you've scoped into one), the same rule as any other edit — see **Format × Locale editing** below.
