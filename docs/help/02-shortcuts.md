## Canvas & View

| Shortcut | Action |
| --- | --- |
| `Escape` | Exit group-edit mode |
| `Ctrl`/`⌘` + `0` | Fit canvas to window |
| `Ctrl`/`⌘` + `1` | Zoom to 100% |

## Layers

| Shortcut | Action |
| --- | --- |
| `Arrow keys` | Nudge 1px (Shift = 10px) |
| `Delete` / `Backspace` | Remove selected layer(s) |
| `Ctrl`/`⌘` + `D` | Duplicate selected layer |

## Copy & Paste

| Shortcut | Action |
| --- | --- |
| `Ctrl`/`⌘` + `C` | Copy selected layers |
| `Ctrl`/`⌘` + `X` | Cut |
| `Ctrl`/`⌘` + `V` | Paste |
| `Ctrl`/`⌘` + `Alt` + `C` | Copy layer style |
| `Ctrl`/`⌘` + `Alt` + `V` | Paste layer style |

## Groups

| Shortcut | Action |
| --- | --- |
| `Ctrl`/`⌘` + `G` | Group selected layers |
| `Ctrl`/`⌘` + `Shift` + `G` | Dissolve selected group |

## History

| Shortcut | Action |
| --- | --- |
| `Ctrl`/`⌘` + `Z` | Undo |
| `Ctrl`/`⌘` + `Shift` + `Z` or `Ctrl`/`⌘` + `Y` | Redo |
